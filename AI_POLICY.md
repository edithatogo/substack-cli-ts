# AI Assistance Policy

AI-assisted work is permitted, but it does not reduce the evidence, security, attribution, or review standard applied to a contribution.

## Requirements

- A human maintainer remains accountable for every merged change and external action.
- Material AI assistance must be disclosed in the pull request using the `ai-assisted` label or an equivalent statement.
- Generated code, tests, documentation, issue content, and dependency advice must be reviewed against repository contracts and authoritative sources.
- Credentials, browser storage, session cookies, private publication content, vulnerability details, and personal data must not be supplied to unapproved models or committed to the repository.
- AI output must not fabricate test results, approvals, reviews, release receipts, registry submissions, or production observations.
- Autonomous agents must stop at credential, authorization, live-write, publication, release, registry, legal, or external-account gates unless explicitly authorized.

## Evidence

AI-assisted changes use the same focused pull requests, required automated checks, Git notes, Conductor traceability, and comment-resolution process as other changes. No second-person approval is required for this solo-maintainer repository.
