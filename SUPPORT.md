# Support

Use GitHub Discussions for redacted usage and integration questions. Use the issue templates for reproducible bugs and bounded feature requests.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/edithatogo/substack-cli-ts/security/advisories/new), not through public issues or discussions.

Do not share session cookies, credentials, browser storage, private publication content, or unredacted traces. This project is maintained by one developer, so response times are best-effort and no service-level commitment is offered.
